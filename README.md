# Hi, I'm Haseeb Arshad 👋

**Senior Software Engineer @ Spadatsoft** focused on building scalable web and mobile applications across modern frontend and backend ecosystems.

I work primarily with **TypeScript, JavaScript, React, Next.js, React Native, Node.js and NestJS**, with a strong interest in application architecture, performance, developer experience and clean, maintainable systems.

Rather than being tied to a single framework, I focus on understanding the underlying engineering problem and choosing the right tools to solve it.

- **Backend Engineering** — Node.js, NestJS, Express, REST APIs and service architecture
